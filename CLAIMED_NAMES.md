# Claimed Bot Names

This repo is intended for many people to create separate private Slack copilots.
Each participant should choose a unique Slack app name and bot display name.

Do not reuse a name that is already claimed or reserved here.

| Bot name | Status | Owner / purpose | Notes |
| --- | --- | --- | --- |
| `JiaxinCopilot` | Claimed | Jiaxin Li / LiGaZn | Personal copilot name already in use. |
| `SeminarCopilot` | Reserved | Seminar host namespace | Reserved to avoid confusion with the host bot. |

## Naming Rules

- Prefer `YourNameCopilot`, `LabNameCopilot`, or another name clearly tied to one owner.
- Do not use another person's name.
- Do not use the host-bot namespace for a private copilot.
- When a new participant claims a name, add it to this file before publishing setup instructions.
